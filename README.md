## Install from a Release

1. Open the latest [Release](https://github.com/martialsystems/amazon-price-per-oz/releases/latest)
2. Download the `.zip`
3. Unzip it
4. `chrome://extensions` → Developer mode on
5. **Load unpacked** → pick the folder that contains `manifest.json`

Chrome will not install the zip as a Store extension. Unzip, then load the folder.
